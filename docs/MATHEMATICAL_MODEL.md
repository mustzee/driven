# 수학적 모델: 메인스트림/서브스트림 자동 구별

## 문제 정의

회의록에서 추출한 카드들 `C = {c₁, c₂, ..., cₙ}`이 주어졌을 때:
1. **메인스트림 카드**: 핵심 아젠다를 구성하는 중요 카드
2. **서브스트림 카드**: 메인 아젠다를 보조하는 부수적 카드

이를 수학적으로 자동 분류하는 방법론

---

## 1. 그래프 구성

### 1.1 카드 그래프 G = (V, E, W)

- **정점 (Vertices)**: `V = {c₁, c₂, ..., cₙ}` (각 카드)
- **간선 (Edges)**: `E ⊆ V × V` (카드 간 연관성)
- **가중치 (Weights)**: `W: E → [0, 1]` (연관 강도)

### 1.2 간선 가중치 계산

두 카드 `cᵢ`, `cⱼ` 간의 유사도 `sim(cᵢ, cⱼ)`:

```
sim(cᵢ, cⱼ) = α·cat(cᵢ, cⱼ) + β·text(cᵢ, cⱼ) + γ·weight(cᵢ, cⱼ)
```

여기서:
- `cat(cᵢ, cⱼ) = 1` if category(cᵢ) = category(cⱼ), else 0
- `text(cᵢ, cⱼ) = |words(cᵢ) ∩ words(cⱼ)| / |words(cᵢ) ∪ words(cⱼ)|` (Jaccard 유사도)
- `weight(cᵢ, cⱼ) = 1 - |w(cᵢ) - w(cⱼ)|` (가중치 유사도)
- `α = 0.3, β = 0.5, γ = 0.2` (하이퍼파라미터)

**간선 생성 조건**:
```
(cᵢ, cⱼ) ∈ E  ⟺  sim(cᵢ, cⱼ) > θ
```
where `θ = 0.2` (임계값)

---

## 2. 중심성 측정 (Centrality Metrics)

### 2.1 PageRank

카드 `cᵢ`의 PageRank `PR(cᵢ)`:

```
PR(cᵢ) = (1-d)/N + d · Σⱼ [PR(cⱼ) · wⱼᵢ / Σₖ wⱼₖ]
```

- `d = 0.85`: 감쇠 계수 (damping factor)
- `N`: 전체 카드 수
- `wⱼᵢ`: 카드 `cⱼ → cᵢ` 간선 가중치
- `Σₖ wⱼₖ`: `cⱼ`에서 나가는 모든 간선 가중치 합

**의미**: 많은 중요한 카드와 연결된 카드일수록 높은 점수

### 2.2 Betweenness Centrality (매개 중심성)

카드 `cᵢ`의 매개 중심성 `BC(cᵢ)`:

```
BC(cᵢ) = Σₛ≠ᵢ≠ₜ [σₛₜ(cᵢ) / σₛₜ]
```

- `σₛₜ`: 카드 `s`에서 `t`로 가는 최단 경로 수
- `σₛₜ(cᵢ)`: 그 중 `cᵢ`를 거치는 경로 수

**의미**: 여러 카드 그룹을 연결하는 "허브" 역할

### 2.3 Degree Centrality (연결 중심성)

```
DC(cᵢ) = deg(cᵢ) / (N - 1)
```

- `deg(cᵢ)`: `cᵢ`에 연결된 간선 수

### 2.4 Eigenvector Centrality (고유벡터 중심성)

인접 행렬 `A`의 고유벡터 `v`:

```
Av = λv
```

카드 `cᵢ`의 고유벡터 중심성 = `vᵢ` (정규화된 고유벡터 성분)

**의미**: 중요한 카드와 연결된 카드가 중요

---

## 3. 메인스트림 식별

### 3.1 종합 중요도 점수

카드 `cᵢ`의 메인스트림 점수 `MS(cᵢ)`:

```
MS(cᵢ) = 0.4·PR(cᵢ) + 0.3·BC(cᵢ) + 0.2·DC(cᵢ) + 0.1·EC(cᵢ)
```

### 3.2 메인스트림 임계값

```
θₘ = percentile(MS, 70)
```

상위 30%를 메인스트림으로 분류:

```
cᵢ ∈ Mainstream  ⟺  MS(cᵢ) ≥ θₘ
```

---

## 4. 아젠다 추출 (커뮤니티 감지)

### 4.1 Louvain 알고리즘

목표: 모듈성(modularity) `Q` 최대화

```
Q = (1/2m) · Σᵢⱼ [Aᵢⱼ - (kᵢkⱼ/2m)] · δ(cᵢ, cⱼ)
```

- `m = Σᵢⱼ Aᵢⱼ / 2`: 전체 간선 수
- `Aᵢⱼ`: 인접 행렬 (가중치)
- `kᵢ = Σⱼ Aᵢⱼ`: 카드 `cᵢ`의 가중 차수
- `δ(cᵢ, cⱼ) = 1` if `cᵢ`, `cⱼ` 같은 커뮤니티, else 0

### 4.2 커뮤니티 응집도

커뮤니티 `Cₖ`의 응집도:

```
cohesion(Cₖ) = |Eₖ| / (|Vₖ| · (|Vₖ| - 1) / 2)
```

- `|Eₖ|`: 커뮤니티 내 간선 수
- `|Vₖ|`: 커뮤니티 내 카드 수

**의미**: 1에 가까울수록 완전 그래프 (강한 응집)

---

## 5. 계층 구조 (Hierarchy)

### 5.1 메인-서브 관계 정의

서브스트림 카드 `cₛ`의 메인 부모:

```
parent(cₛ) = argmax_{cₘ ∈ Mainstream} w(cₛ, cₘ)
```

**조건**:
```
cₛ ∉ Mainstream  AND  ∃cₘ ∈ Mainstream: (cₛ, cₘ) ∈ E
```

### 5.2 고아 카드 (Orphan)

메인스트림과 연결 없는 카드:

```
cᵢ ∈ Orphan  ⟺  cᵢ ∉ Mainstream  AND  ∀cₘ ∈ Mainstream: (cᵢ, cₘ) ∉ E
```

---

## 6. 증명: 메인스트림의 필요충분조건

### 정리 (Theorem)

카드 `cᵢ`가 메인스트림일 필요충분조건:

```
MS(cᵢ) ≥ θₘ  ⟺  cᵢ가 상위 30% 중심성을 가짐
```

### 증명 (Proof)

**(필요조건 →)**
- `MS(cᵢ) ≥ θₘ`라고 가정
- `θₘ = percentile(MS, 70)`이므로
- `MS(cᵢ)`는 상위 30%에 속함 ∎

**(충분조건 ←)**
- `cᵢ`가 상위 30% 중심성을 가진다고 가정
- 정의상 `MS(cᵢ) ≥ percentile(MS, 70) = θₘ` ∎

## 7. 알고리즘 복잡도

### 시간 복잡도

| 단계 | 복잡도 | 설명 |
|------|--------|------|
| 그래프 구성 | O(n²) | 모든 카드 쌍 비교 |
| PageRank | O(k·m) | k: 반복 횟수, m: 간선 수 |
| Betweenness | O(n·m) | 모든 최단 경로 계산 |
| Louvain | O(n log n) | 커뮤니티 감지 |
| **전체** | **O(n²)** | 그래프 구성이 지배적 |

### 공간 복잡도

- 인접 행렬: O(n²)
- 희소 그래프: O(n + m)

## 8. 예시 계산

### 입력 카드
```
c₁: "예산" (w=0.7, cat="경제적")
c₂: "시간" (w=0.8, cat="제약적")
c₃: "가격" (w=0.6, cat="경제적")
c₄: "동행자" (w=0.5, cat="사회적")
```

### 유사도 행렬
```
     c₁   c₂   c₃   c₄
c₁  1.0  0.2  0.5  0.1
c₂  0.2  1.0  0.15 0.3
c₃  0.5  0.15 1.0  0.1
c₄  0.1  0.3  0.1  1.0
```

### PageRank (d=0.85, 10 iterations)
```
PR(c₁) = 0.28
PR(c₂) = 0.24
PR(c₃) = 0.26
PR(c₄) = 0.22
```

### 메인스트림 (상위 50%, n=4이므로)
```
θₘ = 0.25
→ Mainstream = {c₁, c₃}  (경제적 아젠다)
→ Substream = {c₂, c₄}
```

## 9. 검증 방법

### 9.1 정량적 검증

1. **Silhouette Score**: 클러스터 품질 측정
   ```
   s(i) = (b(i) - a(i)) / max{a(i), b(i)}
   ```
   - a(i): 같은 클러스터 내 평균 거리
   - b(i): 가장 가까운 다른 클러스터까지 평균 거리

2. **Modularity**: 커뮤니티 감지 품질
   ```
   Q ∈ [-0.5, 1]
   Q > 0.3: 좋은 커뮤니티 구조
   ```

### 9.2 정성적 검증

- 전문가 레이블과 비교 (Precision, Recall, F1)
- 사용자 피드백 기반 조정

## 10. 한계 및 개선 방향

### 현재 한계
1. 카드 수가 적을 때 (n < 5) 통계적 유의성 부족
2. 하이퍼파라미터 의존성 (α, β, γ, θ)
3. 텍스트 유사도의 단순성 (단어 겹침만 고려)

### 개선 방향
1. **딥러닝 임베딩**: Word2Vec, BERT로 의미적 유사도 계산
2. **동적 임계값**: 데이터 분포에 따라 자동 조정
3. **시계열 분석**: 카드 추가/삭제에 따른 메인스트림 변화 추적
4. **다층 네트워크**: 카테고리별 레이어 분리 분석
